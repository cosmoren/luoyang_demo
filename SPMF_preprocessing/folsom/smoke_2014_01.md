## Reproduction

```bash
micromamba run -n luoyang python SPMF_preprocessing/folsom/gridsat_to_shards.py \
    --start 2014-01-01 --end 2014-01-31 \
    --out-root /work/folsom_dataset/sat_goes_gridsat \
    --workers 8
micromamba run -n luoyang python SPMF_preprocessing/folsom/report_smoke.py \
    --manifest /work/folsom_dataset/sat_goes_gridsat/manifest_20140101_20140131.jsonl --shard-root /work/folsom_dataset/sat_goes_gridsat \
    --report SPMF_preprocessing/folsom/smoke_2014_01.md --figs-dir SPMF_preprocessing/folsom/smoke_2014_01_figs
```
